# 词图（Wordnet）设计与实现

## 1. 设计思想

词图是中文分词算法的核心数据结构，用于将输入文本表示为一个有向无环图（DAG），其中每个节点代表一个可能的词，边表示词之间的连接关系。本实现通过精心设计的类结构和算法，实现了高效、灵活的词图构建和操作。

### 1.1 智能下标（Smart Index）设计

为了简化边界处理和统一索引管理，本实现采用了智能下标系统：

- `-1`：表示词图的起始位置（Start节点）
- `0` 到 `charSize-1`：表示原始文本的字符位置
- `charSize`：表示词图的结束位置（End节点）

这种设计的优势：
- **简化边界条件**：无需单独处理起始和结束位置的特殊逻辑
- **统一索引操作**：所有位置（包括边界）都可以用相同的索引方式处理
- **提高代码可读性**：减少条件判断，使代码更简洁易维护

### 1.2 零拷贝优化

为了减少内存开销和提高性能，词图实现采用了零拷贝策略：

- 直接使用原始的 `char[]` 数组，避免字符串拷贝
- 通过起始位置和长度来引用子串，而不是创建新的字符串对象
- 仅在必要时才进行字符串转换

这种设计可以显著减少内存占用，特别是在处理长文本时效果更加明显。

## 2. 核心组件

### 2.1 Wordnet（词图核心类）

`Wordnet` 是词图的核心类，负责管理整个词图结构：

- **管理顶点行**：每个字符位置对应一个 `VertexRow`，包含该位置所有可能的词
- **智能下标转换**：提供方法将字符位置与智能下标相互转换
- **零拷贝实现**：直接使用原始 `char[]` 数组存储文本
- **节点操作**：提供添加、查找、删除词节点的方法

### 2.2 Vertex（词节点）

`Vertex` 表示词图中的一个词节点，具有双重角色：

- **图顶点**：存储词的基本信息（长度、词性、词频等）
- **链表节点**：通过 `next`/`prev` 指针连接同一字符位置的不同词节点

主要特点：
- 支持绝对词和实际词的区分
- 提供词频和词性的设置与获取
- 支持词节点之间的连接和遍历

### 2.3 VertexRow（顶点行）

`VertexRow` 管理特定字符位置的所有词节点：

- **有序存储**：词节点按长度排序，便于快速查找
- **去重处理**：确保相同长度的词节点唯一
- **高效查找**：利用有序性优化查找性能

### 2.4 Wordpath（词路径）

`Wordpath` 用于描述文本的切分方式：

- **BitSet表示**：使用 `BitSet` 数据结构，`BitSet[i] = true` 表示在第i个字符后插入分割符
- **灵活操作**：支持合并、分裂、拆分等操作
- **高效遍历**：提供词指针机制，无需预先构建完整词列表
- **与词图关联**：与 `Wordnet` 紧密集成，支持自动创建词节点

### 2.5 VertexHelper（顶点辅助工具）

`VertexHelper` 提供创建特殊顶点的静态方法：

- **起始节点创建**：生成线程安全的起始节点
- **结束节点创建**：生成线程安全的结束节点

## 3. 设计优势

### 3.1 性能优化

- **零拷贝设计**：减少内存开销和CPU消耗
- **高效数据结构**：使用BitSet、有序链表等高效数据结构
- **按需计算**：避免不必要的计算和数据结构构建

### 3.2 代码简洁性

- **智能下标**：简化边界处理逻辑
- **统一接口**：核心组件提供一致的操作接口
- **清晰的类职责**：每个类负责单一功能，降低耦合度

### 3.3 扩展性

- **模块化设计**：便于添加新的功能和算法
- **灵活的词表示**：支持各种类型的词节点（如复合词、未知词等）
- **可配置的参数**：关键参数可以根据需求进行调整

## 4. 使用示例

以下是词图的基本使用示例：

```java
// 创建词图
char[] text = "我爱中国".toCharArray();
Wordnet wordnet = new Wordnet(text);

// 添加词节点
wordnet.put(0, 1); // 添加 "我"
wordnet.put(1, 1); // 添加 "爱"
wordnet.put(2, 2); // 添加 "中国"

// 创建词路径
Wordpath wordpath = new Wordpath(wordnet);

// 划定词语
wordpath.combine(0, 1); // 合并 "我"
wordpath.combine(1, 1); // 合并 "爱"
wordpath.combine(2, 2); // 合并 "中国"

// 遍历词路径
System.out.println("分词结果：");
for (Vertex vertex : wordpath.getBestPathWithBE()) {
    System.out.println(vertex);
}
```

本词图实现通过智能下标设计、零拷贝优化和高效数据结构，实现了高性能、低内存占用的词图构建和操作。核心组件之间职责明确，接口统一，便于扩展和维护。该设计为中文分词算法提供了坚实的基础，能够支持各种复杂的分词策略和优化算法。
