## 能做什么

分词、标注、拼音和结构化解析可以单独调用。要换切分路径时，用配方把阶段拼起来。

<CapabilityGrid />

</div>

<SplitSection eyebrow="快速上手" title="几行代码就能分词">

`Znlp` 静态门面覆盖绝大多数场景——分词、拼音、繁简转换、结构化解析，全部通过静态方法完成，不需要接触 `ZnlpSystem` 的生命周期。

需要感知机分词、用户词典或 NER 时，再用 `SegmentRecipe` 按阶段拼装出想要的 `WordSegmenter`。

首次运行会把词典与模型解析成 `data/cache/` 缓存（二元语法表约 40 MB），之后启动直接读缓存，缓存目录可配置。

<Fragment slot="visual">

<Code
  lang="java"
  code={`import dev.znlp.Znlp;

List<Token> tokens = Znlp.segment(text);
for (Token token : tokens) {
    System.out.println(token); // 输出 word/nature
}`}

<SplitSection eyebrow="核心能力" title="分阶段的分词流水线" reverse framed>

- 默认配方 `standard()`：核心词典与候选来源铺候选，二元语法做 Viterbi 选路，再叠人名识别与词性标注，每个阶段都可以独立开关。
- 只要切词和吞吐用 `dictionary()`；要用统计模型分词用 `perceptron()`——线性路径，不跑二元语法。
- 用户词典和纠错词典都在选路之后合并，不参与 Viterbi；纠错词典优先级更高。

<Fragment slot="visual">
  <PipelineDiagram />
</Fragment>

</SplitSection>

<SplitSection eyebrow="可训练的模型层" title="一套感知机框架，五个任务" framed>

- 中文分词、词性标注、命名实体、人名识别、拼音音节切分，都建立在同一套感知机框架上（`dev.znlp.perceptron`）。
- 实现 `PerceptronInstance` 即可接入自己的语料（字符级任务继承 `CharBasedPerceptronInstance`），交给 `PerceptronTrainer` 训练。
- 训练产物可以压缩、落盘，或转成运行时模型；`PosPerceptron.train` 是最清晰的完整范例。
