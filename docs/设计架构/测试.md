# 单元测试约定

znlp 使用 JUnit 5。默认门禁为 `./gradlew :znlp:test`，应稳定、快速、可重复。

## 什么算单测

- 锁**公开契约**：给定输入 → 期望输出或异常；避免依赖实现细节。
- 金标句子宜短、稳定，不依赖本机 `data/` 大语料或外网。
- 模型与词典走 `znlp-resources` classpath（如 `znlp/cws-model`、`znlp/ner/ner.model`）。

## 默认不跑的内容

以下用 JUnit `@Tag` 标记，默认 `test` 任务会 `excludeTags`：

| 标签 | 含义 | 示例 |
| :--- | :--- | :--- |
| `benchmark` | 秒级性能基准 | `FastTextPerfBenchmark` |
| `train` | 训练脚本 | `*Trainer` 的 `main` |
| `performance` | 特征提取等压测 | `PinyinSplitFeatureExtractorPerformanceTest` |
| `heavy` | 依赖本机 `data/` 大语料或加载全量词典/模型，内存占用大；CI 无 `data/`，也不应运行 | `CoreDictionaryTest`、pinyin 包词典测试 |

需要时单独跑：

```bash
./gradlew :znlp:test -PincludeTags=benchmark
./gradlew :znlp:test -PincludeTags=heavy   # 仅本机有 data/ 时
./gradlew :znlp-benchmarks:jmh   # 分词 JMH，见 [基准.md](基准.md)
```

演示与训练脚本统一放在 [znlp-examples](../../znlp-examples/README.md) 模块，测试源码集里不再放带 `main` 的类，避免被误当成门禁。

## 资源加载

- 优先 `NlpResourceLoader` + `TestHelper.createTestConfig()`。
- 临时语料用 `Files.createTempDirectory` / `createTempFile`，测完删除。
- 禁止在断言里写死开发者本机绝对路径。

## 命名与位置

- 测试类放在 `znlp/src/test/java`，包名与生产代码一致。
- 门面 API 用 `ZnlpXxxTest`；模块内用 `XxxTest`。
- `*Benchmark*`、`*Trainer*`、`*Demo*` 不应在无标签情况下进入默认 test。

## 验收

- `./gradlew :znlp:test` 全绿，且不跑训练与基准。
- README 中列出的 `Znlp.*` 能力至少有一条会失败的断言。
- 不设 JaCoCo 百分比闸；覆盖率需要时另加插件。
